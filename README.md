# 🍼 Rastreador de Alimentación del Bebé — Aissa

Una aplicación web ligera, optimizada para móviles, para registrar las tomas del recién nacido en tiempo real. La creé para uso personal durante el primer mes de mi hija.

## Funcionalidades
- Selecciona al cuidador (Bryan / Lucía) con un solo toque.
- Detecta automáticamente la hora actual y la próxima toma prevista.
- Registra la cantidad de leche materna y fórmula (onzas).
- Guarda cada entrada directamente en Google Sheets mediante Apps Script.
- Funciona sin conexión desde cualquier navegador móvil.

## Tecnologías utilizadas
- HTML / CSS / JavaScript
- Google Apps Script (API de Sheets)
- Alojada en GitHub Pages

## Contexto
La creé para coordinar los turnos de alimentación con mi esposa durante el primer mes de nuestra recién nacida, a la vez que gestionaba los altos niveles de bilirrubina (cada 3 horas).
