# 🍼 Aissa — Seguimiento de la Alimentación del Bebé

Una aplicación web ligera, optimizada para móviles, para registrar las tomas de Aissa en tiempo real.
Desarrollada durante su primer mes de vida.

## Funcionalidades
- Selecciona al cuidador (Bryan / Lucía) con un solo toque.
- Detecta automáticamente la hora actual y la próxima toma prevista.
- Registra la cantidad de leche materna y fórmula (onzas).
- Guarda cada entrada directamente en Google Sheets mediante Apps Script.
- Funciona desde cualquier navegador móvil, sin necesidad de instalación.

## Tecnologías utilizadas
- HTML / CSS / JavaScript
- Google Apps Script (API de Sheets)
- Alojada en GitHub Pages

## Contexto
Desarrollada para coordinar los turnos de alimentación del recién nacido con mi esposa Lucía durante el primer mes de Aissa, mientras controlábamos los niveles elevados de bilirrubina (cada 3 horas). Un problema real, resuelto con código.

# 🍼 Aissa — Baby Feeding Tracker

A lightweight mobile-first web app to track Aissa's feeding 
sessions in real time, built during her first month of life.

## Features
- Select caregiver (Bryan / Lucía) with one tap
- Auto-detects current time and nearest expected feeding
- Logs breast milk and formula amounts (oz)
- Saves every entry directly to Google Sheets via Apps Script
- Works from any mobile browser, no install needed

## Tech Stack
- Vanilla HTML / CSS / JavaScript
- Google Apps Script (Sheets API)
- Hosted on GitHub Pages

## Context
Built to coordinate newborn feeding shifts with my wife Lucía 
during Aissa's first month, while managing high bilirubin 
monitoring (every 3 hours). A real problem, solved with code.
